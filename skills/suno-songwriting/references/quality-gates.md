# 质量门禁（QA）

## 硬约束（fail 不可交付）

| ID | 条件 | 检查方法 |
|---|---|---|
| H1 | 标题存在；用户指定标题必须逐字保留 | 对照请求与产物 |
| H2 | 创作简介 100–150 汉字 | 只统计 `\u4e00–\u9fff` |
| H3 | Genre、Mood、Tempo、Instrumentation、Vocal Style、Production 均存在 | 文本比对 |
| H4 | 有独立 `Style of Music` 纯文本代码块，≤1000 个 Unicode 字符 | `scripts/validate.py` |
| H5 | 完整 Lyrics `text` 代码块，Verse、Pre-Chorus、Chorus、Bridge、Outro 存在 | `scripts/validate.py` |
| H6 | 不覆盖用户已经指定的标题、语言和迭代范围 | 请求对照 |
| H7 | 不虚构已生成音频的事实、不声称未执行的试听/发布 | 来源与输出对照 |

## 表现门禁（review，不能用静态脚本冒充试听）

| ID | 问题 | 失败信号 |
|---|---|---|
| C1 | 主题是否有具体冲突和人物动机 | 只有抽象主题标签 |
| C2 | 主歌是否有至少两个可感知的具体画面 | 每句都在表达观点 |
| C3 | Hook 是否能短句重复且不会强迫绕口 | 只有长句，重复时含义失焦 |
| C4 | Bridge 是否引入新信息/情绪反转 | 机械复述副歌 |
| C5 | 讽刺是否针对机制、行为而非无端攻击 | 只有训斥没有画面 |
| C6 | 双语是否自然、语义有递进 | 英文只作装饰或语法错误 |
| C7 | 单句气口、押韵、节奏是否适宜演唱 | 书面化长句密集；最终仍需试听 |

分类：`PASS`、`FAIL`、`UNVERIFIED`；仅 H1–H7 通过不等于 C1–C7 经独立证实。因输入缺失无法判断写 `UNVERIFIED`，不得填充假证据。
