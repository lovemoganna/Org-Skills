# 歌词审读标尺

评估顺序：事实边界 → 人物/场景 → 叙事机制 → 旋律 Hook → 声线与配器适配。

- **真诚批判**：通过一张票根、练习微笑、数据报表或空座位展现机制对人的影响；不堆“资本”“算法”“时代”等抽象名词。
- **主歌与副歌分工**：主歌交代事件和细节；副歌给一句可复述的冲突；Bridge 揭露角色不愿承认的真相；终副歌使同一 Hook 产生新含义。
- **韵脚**：选稳定主韵，但允许对话语气打破韵脚；不以错乱语序换押韵。词语重复必须提升节奏或意义。
- **情感密度**：至少一处自我矛盾、一处细节映射情感、一处推进后的选择。拒绝“我很痛苦/世界很假”式解释性堆砌。
- **双语意义**：例如 `I'm fine`（假面）→ `Move on`（社会命令）→ `I'm not fine`（自我允许）；只作为机制示例，不应固定写入每首歌。
- **可唱性**：检测含有多个从句、连续生僻发音、英语词音节过多的行；写成容易落在节拍上的短句；实际效果须听真实生成音频才能评价。

只给有证据的修改意见；保留有效段落，不因例行“优化”过度重写。
