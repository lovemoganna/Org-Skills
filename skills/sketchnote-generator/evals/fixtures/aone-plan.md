# AI 拟人化编排系统规划

## 一、系统架构

### 1.1 核心概念

```
Persona (人格) × Skill (技能) = Agent (智能体)
Agent × Agent = Squad (协作团队)
Agent + Workflow = 流程编排
```

### 1.2 数据模型

```typescript
// Agent 定义 - 组合 Persona + Skills
interface Agent {
  id: string;
  name: string;
  description: string;
  personaId: string;        // 绑定的人格
  skillIds: string[];       // 绑定的技能列表
  config: AgentConfig;      // 运行配置
  visual: AgentVisual;      // 视觉样式
  isBuiltIn: boolean;
}

// Squad 定义 - 多个 Agent 协作
interface Squad {
  id: string;
  name: string;
  description: string;
  agents: SquadMember[];   // Agent 成员列表
  orchestration: OrchestrationType;
  workflow?: Workflow;     // 可选的流程定义
}

// Workflow 定义 - 流程编排
interface Workflow {
  id: string;
  nodes: WorkflowNode[];
  edges: WorkflowEdge[];
  variables: Variable[];
}

type WorkflowNode = 
  | PersonaNode      // 人格节点
  | SkillNode        // 技能节点  
  | AgentNode        // Agent 节点
  | ConditionNode    // 条件分支
  | LLMNode          // LLM 调用
  | OutputNode;      // 输出节点
```

### 1.3 编排模式

| 模式 | 复杂度 | 适用场景 |
|------|--------|----------|
| **快速组合** | 低 | 简单场景，Persona + Skills 直接组合 |
| **流程编排** | 中 | 复杂逻辑，条件分支，多步骤处理 |
| **Squad 协作** | 高 | 多 Agent 讨论，团队协作 |

## 二、可视化编辑器规划

### 2.1 编辑器架构

```
┌─────────────────────────────────────────────────────────────┐
│  工具栏 (保存/运行/调试)                                      │
├──────────┬──────────────────────────────────┬───────────────┤
│  节点库  │                                  │   属性面板    │
│          │                                  │               │
│ • 人格   │      画布 (无限缩放)              │  • 节点配置  │
│ • 技能   │                                  │  • 参数设置  │
│ • Agent  │    [Persona] ──► [Skill]         │  • 预览      │
│ • 逻辑   │           │                      │               │
│ • LLM    │           ▼                      │               │
│ • 输入/输出│      [Output]                  │               │
└──────────┴──────────────────────────────────┴───────────────┘
```

### 2.2 节点类型

| 节点类型 | 图标 | 功能 |
|----------|------|------|
| **Persona** | 👤 | 加载人格配置 |
| **Skill** | 🔧 | 调用技能工具 |
| **Agent** | 🤖 | 调用完整 Agent |
| **Condition** | 🔀 | 条件分支判断 |
| **LLM** | 💬 | 直接 LLM 调用 |
| **Input** | 📥 | 用户输入 |
| **Output** | 📤 | 结果输出 |

### 2.3 交互设计

- **拖拽添加**: 从左侧节点库拖拽到画布
- **连接**: 从节点边缘拖拽创建连接线
- **自动布局**: 一键整理节点布局
- **小地图**: 快速导航大型流程
- **撤销/重做**: 支持历史操作回退
