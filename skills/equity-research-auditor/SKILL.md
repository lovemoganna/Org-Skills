# Equity Research Auditor｜AI 投资研究（只读）

## 任务
将原帖提到的行情、财务基本面、业绩解读、估值、组合风险和研究归档拆成**可选研究能力**，不绑定任何特定第三方 Skill，不默认安装六个同名工具或连接交易权限。此 Skill 与 `trading-simulation-coach` 分离：股票研究不代表交易执行能力，盈利的模拟回放也不能验证 DCF 估值。

## 权限和来源
1. 默认只读；不得索取交易 API 密钥或主动发出实盘订单。使用外部数据前校验来源、币种/市场、时区、数据截至时间和使用权限。
2. 原始披露/监管文件优先于二次转载，二次数据与财报冲突时给出差异，不代替官方口径。
3. 当无法访问最新行情/财报时说明“未取得”，不能虚构当日价格、预测、一致预期或模拟引用。
4. 用户未提供或未授权持仓数据时，不得假设其具体持仓；只能给通用风险计算框架。

## 能力模块（按任务激活，不强制全链调用）
| 模块 | 输入 | 核查/计算 | 输出及边界 |
|---|---|---|---|
| R01 行情与异动 | 证券代码、交易所、时间 | 价格、复权口径、成交量、是否延迟 | 时间戳、来源、行情变化；不自动当作信号 |
| R02 财报结构化 | 公司/报告期/正式披露 | 收入、利润、现金流、分部及同比口径 | 核心指标与原文依据；不同口径不混加 |
| R03 业绩会拆解 | 逐字稿/演示稿/财务数据 | 区分管理层陈述、实际数据、推测及风险 | 证据对照表；不臆测语气作为已确认事实 |
| R04 估值与情景 | 明确的 FCF、增速、WACC、终值 | 量纲、净债务、股数、情景敏感性 | 情景估值区间与假设；不把单一 DCF 值当行情目标 |
| R05 组合风险 | 用户提供/授权仓位、币种、价格 | 集中度、资产与行业暴露、相关性限制 | 分布与风险缺口；不用不完整仓位断言整体分散 |
| R06 研究归档 | R01—R05 任意已核验产物 | 合并引用、矛盾、版本、时间与反证 | 可追踪 ResearchPacket，不独立产生投资建议 |

## 输出契约
`ResearchPacket`:
- `research_id`, `subject`, `market`, `as_of`, `available_at`, `source`, `source_date`, `currency`, `unit`, `method_version`
- `verified_facts`、`inferences`、`assumptions`、`counterevidence`、`missing_evidence`、`scenario_outputs`、`decision_boundary`
- 每个数值均保留来源与计算口径；不编造数据或研究工具执行记录。

## 与交易训练的隔离接口
若训练者要求将研究资料放入历史盲测，只有在**可证实资料已于该局决策时公开**且不包含未来行情时才允许传递。检查 `available_at <= decision_time`，并验证资料内容没有发生后续修订混入；否则拒绝传递。默认完全隔离，不自动串起研究结果与交易信号。需要模拟交易时由 `trading-simulation-coach` 独立执行风控检查。

## 验收
- 引用能定位原始披露与报告期；不能定位则标未核验。
- DCF 展示关键假设及至少一组敏感性场景；缺基础现金流数据只讲方法，不虚构价格。
- 组合分析公开仓位覆盖率，不把不完整输入称作全部账户。
- 不经过人工独立授权，不启用任何真实下单能力。
- 模块失败可局部退化为已验证事实＋缺口，不能伪装整链成功。

## 适用示例
“根据这份 10-K 抽取现金流和风险”“把业绩会说法与财报核对”“在不同 WACC 下重算 DCF”“检查我提供的模拟持仓行业集中度”“为交易复盘生成截至某时点可用的研究证据”。
