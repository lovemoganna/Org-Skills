# S1 · Intent

把原话映射为可追溯的 IntentCard，不替用户填补动机。

输入：用户请求、当前会话中直接相关的事实、授权文件/项目环境。
执行：保留字面行动与对象；从“做完后要干什么”还原动机；分别记 `[明确]`、`[推测]` 和 `[未知]`；给每项明确内容附来源，推测只作为候选。

若未知答案会改变高风险或不可逆方案，且无法通过检查现有文件和工具确认：最多提一个问题，可使用 `atoms/single-question.md`。若低风险且可逆，记录 `defaults` 后推进；交付时标注。

模糊描述（如“像专业产品一样”）可用 `atoms/define-observable.md` 提出候选可观察特征，但不得擅自将候选当成用户验收要求。

产物：`templates/intent-card.md`。
**边界**：S1 的局部辅助不创建执行链、重试或跨阶段路由；这由 S3 负责。
自检：每条 goal 有证据；未知已处置；没有将推测升级为授权。
