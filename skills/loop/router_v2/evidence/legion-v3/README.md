## 同模型对照

- S1 普通模型和军团均正确。直接运行观测约 0.75 秒，军团约 92.6 秒，后者含模型交接和共享工作等待。对照非盲，只能说明该次运行没有速度或正确率优势。
- G1 独立普通模型结果通过相同冻结代码验收。直接组只执行本地代码验证，没有做远端提交，不能比较两组业务闭环。
- 两个样本未形成足以证明真实收益的配对实验。默认入口的通用适配、自动修正验收失败和无需人工接管的证据仍未达到 V3 晋升门槛。PR #122 保留草稿和候选范围。

证据包含冻结任务、原始回执、复核脚本、隔离表格及 MP4。GitHub 四项的原始连接器日志有部分写入中断，保留压缩残片与随后取得的独立远端回读。未使用外部模型 API。
