## 证据边界

- 六个最终结果均有独立业务验收。内部状态保留 COMPLETED_UNVERIFIED，最终结论来自另行取证的 verification。
- 在首次环境中断后，一次临时目录中的 E01 运行丢失，使用原冻结任务在持久工作区重跑。E02 初测、收紧权限复验及按目标生成公式共用了三个隔离工作簿。E05 在同一用户任务内由 Work 启动新的宿主实例。当前证据覆盖活动会话接管和有检查点的恢复。
- E03 与 E06 均使用本地 SQLite 和真实 GitHub 连接器，SQL 运行器和 Git 独立复算分别留下结果。E06 验证跨工具只读数据传递；这两项不覆盖生产数据库或跨系统事务。
- 安全写入限单个预期 GitHub 分支头与文件，或确认独占写入的隔离 Sheets 工作簿。多人并发编辑、无人值守后台调度、主机及持久存储同时丢失均无实测结论。
