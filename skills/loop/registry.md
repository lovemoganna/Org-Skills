# Atom Registry

状态：`draft` = 尚无跨任务实证；`verified` = 至少两项不同真实任务通过；`retired` = 被取代。

| 原子 | 归属 | 输入 | 输出 | 状态 |
|---|---|---|---|---|
| single-question | S1 辅助 | unknowns, defaults | 唯一关键问题与可逆默认 | draft |
| define-observable | S1 辅助 | phrase, context, reference | 带来源的可观察特征候选 | draft |
| decompose-mece | S2 辅助 | goal, necessary_conditions, scope_out | 子任务与条件覆盖矩阵 | draft |
| write-acceptance | S2 辅助 | necessary_conditions, deliverable_type | 有证据途径的验收表 | draft |
| verify-against-goal | S4 验证 | intent, acceptance, output, constraints | 只读结果验收 | draft |

此表登记模块用途与归属；S3 可选择任务执行所需 atom，S1/S2 内部辅助不等于跨步骤 chain。增加 atom 前先查职责重叠。
升级 verified 时，在本表补齐至少两份不同真实 run 的证据地址；没有证据不得更改状态。
