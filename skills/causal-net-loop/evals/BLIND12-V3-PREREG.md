# 因果 Skill V3 盲评预注册

## 假设

以冻结 Baseline 为起点，只在「造因」追加一条核验规则。可改变判断或处置的独立证据缺口，应明确核验手段、判据及后续动作。存在记录冲突时查原始来源、备选值、录入和口径差异。试点给出停止或回滚条件。

旧 N01、N02、N04、N07、N11、N12 只用于开发回归。新集为十道复杂题和两道负对照，题面与旧集不同。主线程设计新集并冻结，其设计偏向本次修复直接作用的任务。新题结果只支持此样本上的结论。

## 执行与门槛

- 用两个新 Work 执行线程按 N01–N12 顺序批量答题，均配置 `gpt-6.2-sol` / `medium`，均不继承主会话。每臂仅收到一个完整 Skill 和同样的题面。本地工具只用于读取指定输入和存档结果。
- 第三条同配置的新线程只看每题随机匿名的答案和评分材料。哈希锁定评分后才恢复解盲密钥。
- 沿用 PR #115 的原评分程序、五维权重、0–2 分量表、硬失败规则和晋升门槛。复杂题至少 8 胜、最多 1 负，平均提升至少 5 分，字符数比中位数至多 1.25。两臂共 24 份答案均无硬失败，两臂分别通过两道负对照。
- 以本文件所在的预注册提交冻结题集、Skill、评分条件。看到输出后不修订本次输入或计分。一次回归加一次新题盲评即可作出本轮去留决定，单次结果不视为总体效应。
