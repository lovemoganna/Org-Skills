**权重**：机制 30%、双主体覆盖 25%、事实/推断 20%、区分证据 15%、精简 10%；每维匿名评分 0–2，按权重换算 100 分。

**发现**：
1. Baseline 开头声称“材料证实两恶相互塑造”，后文却承认陈的剥削机制未被证实；证据强度不一致。匿名评分据此扣减机制与事实维度。
2. Candidate V2 更清楚地区分“获利后继续冒险”的正反馈和“阶层叙事作为原因或事后合理化”这两种机制，但“破网口：首次得手后的追责”对电影文本理解贡献有限。
3. 无 Skill 也提出了两种竞争机制与明确反证，且匿名评分与 Candidate 并列；因此**无法证实 Skill 相比普通模型增加了因果洞察**。
4. 三臂均未充分证实真正的双向反馈，只是解释了富商成为目标和抢劫者不断升级的机制。
5. **评分口径缺陷**：盲评把 Candidate 的“超过 500 字附近”作为精简扣分依据，但以 Unicode 汉字数计为 458，低于题面“500 汉字”限制；原始锁分保留，不进行事后改单。无 Skill 为 526 汉字，确实超限。这说明匿名评分器的长度判断存在误差，不能把 95 分当作精确能力量表。
