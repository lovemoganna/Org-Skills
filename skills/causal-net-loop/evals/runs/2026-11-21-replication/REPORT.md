# Causal Net Loop × KeyPoint Loop 独立复验

**决策。** 保留现有版本。当前证据不足以支持默认启用 Causal、Keypoint 或全量组合，短指令候选同样不晋升。首轮组合 +3.18 分在新案未复现，新轮 −0.66，合并 20 案 +1.64，95% CI [−0.17, +3.45]。两名评审分别给出 −0.63 和 −0.70 的新轮差值，方向一致。

## 执行

沿用[首轮存档](../2026-11-21-four-arm/)的正式 Skill blob、A–D 处理字节、共同任务格式和评分权重。新案覆盖四类各 2 件，合并四类各 5 件。原始材料和 Git / Google Sheet 可见历史按实体排重，排除与前轮同一行动的 MyTrade。历史可见之外及公开材料的模型训练暴露无法验证。八案判例及监管公告是公开证据，分别按公告时点及法律进程使用。处理文本、题面、短候选、评分均在 01:29:30 UTC 冻结，原文件逐字比对通过。 [冻结条目](freeze/cases.json) · [预定判定与方法](freeze/protocol.json)

五个同配置 Work 原生执行线程各一次答完 8 个新案，两个无父上下文的评审线程各对匿名 40 份、80 段全部评一次。两名评分独立提交并锁定后揭盲。精确后台部署模型、费用和 Token 未暴露。各线程不使用外部模型 API 或额外搜索。80 段均在 500 字符内，无重试。评审使用同一匿名答卷，按各案随机化，不读取组别映射。没有人工独立复评。 [完整提示](prompts/) · [原始回答与运行时记录](raw/) · [匿名包、评分、哈希及映射](review/)

## 三个案例

1. **A04 KuCoin。** Causal 与组合的调查各 +15 分。Causal 写清位置误标、样本口径错误等会如何下调美国客户暴露估计。组合写出个案升级/降级。该提升未在多数案件重现。 [DOJ 认罪公告](https://www.justice.gov/usao-sdny/pr/kucoin-pleads-guilty-unlicensed-money-transmission-charge-and-agrees-pay-penalties)
2. **F04 Buchanan。** 组合调查 −3.75。它提供临时保护的解除条件，未写清反证成立时撤回哪条供应商泄露归因。基线明确指出出金早于暴露或证实本人授权应降级。 [DOJ 量刑公告](https://www.justice.gov/usao-cdca/pr/british-national-sentenced-6-years-federal-prison-hacking-companies-and-stealing-least)
3. **A05 CoinList。** 短指令完整流程 −7.50。调查明确什么证据会推翻居住地判断，但漏列和解中的两项 30 万美元。复盘找回了金额口径，没交代原案克里米亚适用范围。这是答卷遗漏，不能据此推断必由指令或长度造成。 [OFAC 执法公告](https://ofac.treasury.gov/media/932406/download)

## 短指令候选

只在新的 8 案比较。E 相对 A **-1.76**，95% CI **[-5.04, +1.53]**。E 相对 D **-1.09**，95% CI **[-3.35, +1.16]**。两名评审均认可的目标命中为 A **15/16**、D **14/16**、E **14/16**。预定门槛为对 A 至少 +3 且 CI 下界大于 0、对 D 下界至少 −2、无增量严重错误且目标命中提升。只有严重错误条件通过。组合对两单用的同阶段优势也未获确认。短指令不进入候选试用，正式 Skill 不改。

当前题面已经要求反证和适用范围，基线在新案例对此覆盖 15/16，说明这两个补丁在本任务的新增覆盖有限。下一次若进入更难的真实初审实验，应去掉共享题面里的重复提示，用冻结的原始案卷与可导致不同业务决定的具体证据衡量；若改用独立评分盲审和复跑，需要另行采样。这里不把实践建议视为已验证的修复。

## 复算

从同一提交复制两个兄弟归档目录至临时目录。进入本目录运行 `sha256sum -c freeze.sha256`，移动其副本的 `result.json` 后运行 `python analyze.py analyze`，与原 `result.json` 比较。评分文件锁定哈希由脚本自动核验。
