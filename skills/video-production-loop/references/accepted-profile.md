# 已验证案例与可选预设

本预设来自 2026-11-07 用户实际接受的《为什么努力不一定成功》制作与修订。它是一个可复现的起点，不是其他主题必须复制的产品定义。

| 项目 | 本案例最终选择 | 迁移时的判断 |
|---|---|---|
| 视频 | 30 秒，1920×1080，30fps，900 帧 | 依平台/内容决定，不锁死 |
| 视觉 | 深色底、暖色强调、简洁信息图 | 服从品牌；一景一个信息目标 |
| 模板 | 问题、因素卡片、路径对比、步骤、结论 | 按关系选择，可新增 |
| 配音 | Edge `zh-CN-YunxiNeural`，`+10%` | 用户认为前版偏慢后调整；需试音 |
| 句长 | 每段实际 4.728–5.472 秒，镜头 6 秒 | 用真实生成时长，不按字符数保证 |
| 留白 | 音频前 80ms；后面补齐场景 | 按节奏决定，不滥用长静音 |
| BGM | 用户提供大提琴曲，较强区间；低音量 | 不携带该歌曲；新文件重新选段和配平 |
| 混音 | 按整片 RMS 比对白低约 18 dB | 是起始点，绝非固定 0.0207 音量 |
| 标记 | 移除 Codex/Remotion 角标 | 工具名不自动出现在成片中 |

真实经验：Windows Huihui + 为时长进行约 1.5 倍后期加速被用户否定；换 Edge 神经声音后效果改善，用户继续要求更快、更连贯。仅提高语速却让每段剩更多空白并不能改善整体节奏；需要同时处理措辞、停顿和时间线。

证据边界：实际渲染、900 帧、完整解码、抽帧和混音信号验证通过；记录的相关性约 0.99993、峰值约 0.593 证明该样片的信号与文件属性，不证明所有新样片质量。制作者未人工听审，用户的后续认可提供了该次主观效果反馈。批量新主题仍需逐项检查。
