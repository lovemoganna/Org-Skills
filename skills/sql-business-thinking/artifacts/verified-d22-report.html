核心判断 / 决策解释

完成状态占比不能单独用于入金、出金方向排名

不能仅凭一个分母下的 completed 占比给两个方向的业务表现或风险排序；辅助终态分母下方向排序发生翻转。

应如何解释这份结果在全部记录与仅终态记录两种分母下，方向排序翻转。不能使用单一 completed 占比给业务风险或运营优先级排名。
证据：D11 已验证历史交易记录交付范围：分析报告，不是实时监控看板

两种分母口径，方向排序翻转

终态记录口径仅为辅助敏感性检查，不替代全量记录占比。

单位：订单记录。状态组互斥，计数来自已执行 SQL。

解释边界与下一步

证据支持口径判断，不支持实时处置或根因判断。

当前限制

  • 样本总量仅 25 条；属于历史状态快照，不代表当前订单状态。
  • failed 与 cancelled 不代表同一种业务原因；pending 与 processing 不等于现时仍在处理。
  • D11 未返回逐笔 UID、失败原因、状态流转日志或损失信息。
  • 终态分母是辅助敏感性口径，不代替全量分母；敏感性结果由同一 D11 聚合派生，未执行新 SQL。
  • 未提供运营动作阈值，不能从比例或状态数直接推出处置建议。

查看原始 SQL（已记录执行）

D10 锁定 SQL 与 D11 执行 SQL 逐字一致；只读 fiat_transactions。

-- D10 design only: do not execute until D11.
-- Source: D01-authorized fiat_transactions view created from read_xlsx.
-- Grain: one output row per direction; each input row is one fiat order.
-- Scope: all authorized fiat transaction records, no date filter.
WITH per_direction AS (
    SELECT
        direction,
        COUNT(*) AS total_order_records,
        COUNT(*) FILTER (WHERE status = 'completed') AS completed_records,
        COUNT(*) FILTER (
            WHERE status IN ('pending', 'processing')
        ) AS in_progress_records,
        COUNT(*) FILTER (
            WHERE status IN ('failed', 'cancelled')
        ) AS terminal_noncompleted_records,
        COUNT(*) FILTER (
            WHERE status IS NULL
               OR status NOT IN ('completed', 'pending', 'processing', 'failed', 'cancelled')
        ) AS unknown_status_records
    FROM fiat_transactions
    GROUP BY direction
)
SELECT
    direction,
    total_order_records,
    completed_records,
    in_progress_records,
    terminal_noncompleted_records,
    unknown_status_records,
    CAST(completed_records AS DOUBLE)
        / NULLIF(total_order_records, 0) AS completed_state_share
FROM per_direction
ORDER BY direction;
