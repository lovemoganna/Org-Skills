# 实际回归：长问答被写成一整块引用

## 失败输入
《高效学习手册》第18章炼化稿把八道自查题写成连续引用：

~~~markdown
## 八个自查问题
> **Q18-1**：你希望两周后得到什么判断？
> **Q18-2**：上午和晚上表现有什么差异？
> **Q18-3**：哪种环境更适合当前任务？
~~~

Markdown 将其读作一个引用块，读者扫描题号时层级拥挤。

## 可读成品
~~~markdown
## 八个自查问题

1. 你希望两周后得到什么判断？
2. 上午和晚上表现有什么差异？
3. 哪种环境更适合当前任务？

## 来源与引用
题目 1—3 分别对应原章 Q18-1—Q18-3；题序与文本内容不改变。
~~~

## 规则边界
- 需要顺序的动作与多道问答采用有序列表；并列概念采用项目符号，不得为“漂亮”而统一加编号。
- 复合标识如 Q18-1、CASE-103 必须在来源索引或正文中保留精确映射；被链接引用时不能静默改名。
- 正文采用短动作提示，只在确有助于扫读时加粗，不堆砌 01｜①、一、等多套序号。
- 逐字引用、研究资料、代码块内的源编号属于合法保留对象，检测器不判内容优劣。
- 不能把格式校验通过冒充审美评价；要检查实际呈现与可读性。
