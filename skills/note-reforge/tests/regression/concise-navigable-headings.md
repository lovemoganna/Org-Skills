# 回归：长标题泄露论证，正文失去主次

## 真实失败样本
来源：此前实测《学习方法不适合我时，怎样验证、调整和保留？》的 Markdown 草稿。
旧标题：
- 学习方法不适合我时，怎样验证、调整和保留？
- 遇到什么问题，先做什么
- 一次小实验：先证实效果，再决定保留
- 个人特征是观察变量，不是固定身份〔补〕
- 定期复盘：不要把年度检查当成唯一退出点
- 证据边界
- 八个自查问题
- 来源、许可与插图

## 直接可用的标题目录
- 学习方法的选择与迭代
- 方法选择
- 方法实验
- 学习特征
- 定期复盘
- 证据边界
- 自查问题
- 来源与附图

标题下面的正文保留“先证实效果再决定是否保留”“不能用人格标签替代观察”等完整论证。〔补〕标记保留到对应正文，原有自查题与证据引用不删除。

## 独立泛化与保护性反例
- 旧：数据看板为什么不能直接生成，以及怎样保证指标可靠？→ 新：指标可靠性。
- 旧：权限边界：为什么所有执行都不应该默认批准→ 新：权限边界。
- 「其他」很短，但信息导航价值低，仍需改名。
- 「制裁名单筛查」「事故复盘」「故障证据」短而能定位，保留。
- 法规正式名称、论文完整标题、必要的版本/专有名词，以及明确要求使用问句的出版物，允许保留长标题。
- 修改 Org 小节名时不得丢失 `CUSTOM_ID` 或按标题文字生成的站内引用。
- 所有检查器只给编辑复核候选，不能将字符长短充当语义质量判定。
