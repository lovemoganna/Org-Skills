# 实测回归：从解释原文转为直接交付知识

## 用户实际指出的失败
原文提出五个观察维度：能量节奏、刺激偏好、社交偏好、启动难易、注意稳定性。可将其整理成一页个人学习配置表。

## 直接可用的成品
个人学习配置表应记录五项实际表现：能量节奏、刺激偏好、社交偏好、启动难易、注意稳定性。每项记录具体行为和结果，不能用性格标签替代观察。

## 相邻失败
原文一方面要求按原方法执行，另一方面强调灵活调整。需要区分两个判断。

## 相邻改写
测试阶段先固定方法，获得可比较的结果后，再按实际效果调整环境或策略。

## 不得误删的事实归属
“两周足够试出大部分方法”是作者的实践建议，缺少可复现的样本与条件，不能当作通用效果保证。

### 人工验收边界
- 不能把「原文提出」替换成「材料指出」就算修复。
- 不能删掉来源身份、原始事实、数字、引文、不确定性及版权说明。
- 当用户确实要求文献或版本比较时，来源叙述本身属于交付内容。
- 结构脚本只能找高置信度疑似段落，不会自主衡量知识增量与事实真假。
