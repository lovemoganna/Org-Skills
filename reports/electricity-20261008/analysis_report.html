五、复杂问题、竞争解释与稳健性（Gate 3）

同序列周内/周末读数差异

确认事实：共 370 条有效配对序列，周末均值较低 97 条、较高 63 条；配对差值平均 -3.34904（原文件单位未知）。

竞争解释：不同时期的季节变化、观测记录日期偏差或零值机制可能影响差异。

局限：仅是样本内的描述性比较，未识别节假日和天气，不能证明周末造成用电变化。

全零序列存在，合并平均值需单独披露

确认事实：全部 370 条序列中，全零序列 210 条；其进入总体均值会改变总体结构。

竞争解释：全零可能表示未启用、真实零耗用或导出时填零，现有TXT无法区分。

局限：不得把全零序列直接判定为数据丢失、停电或客户流失。

绝大多数零值来自210条全零序列

确认事实：全零序列贡献 2099790 个零值，其余曾出现非零读数的序列贡献 26689 个零值；总体均值 313.97763，仅保留曾出现非零读数的序列均值 726.07327（原文件单位未知）。

竞争解释：全零源的业务含义不明，可能为未启用、真实零负荷或源端补零。

局限：不能据此认定全零记录必须删除；两种均值反映不同统计总体，均应披露。

日度/月度对比需排除边界不完整日期

确认事实：本样本每日最多 96 个时间点；不完整日期：[(datetime.date(2011, 1, 1), 95), (datetime.date(2011, 4, 15), 16)].

竞争解释：首尾日期为文件截断边界，非日内用电自然减少。

局限：不得将首尾不完整日期直接当成完整自然日，也不得将4月视作完整月份。

控制全零序列与边界截断后的周末差异

确认事实：完整日和160条候选非零序列中，可比较序列 160 条，周末较低 40 条、较高 120 条，平均配对差值 0.90251。

竞争解释：日历、季节、用户类型仍可能解释读数变化。

局限：未控制天气、节假日与营业属性，不能从此推断因果关系。

周内/周末结论对首尾日期过滤高度敏感

确认事实：依次保留或剔除首尾日期的真实配对差值：[('all_dates', 370, 97, 63, -3.34904), ('drop_both', 370, 40, 120, 0.39028), ('drop_first', 370, 36, 124, 0.63076), ('drop_last', 370, 103, 57, -3.58952)].

竞争解释：首次边界日期自身具有不同的日内或日历负荷形态；仅凭数据不能判断是节日、截断还是其他原因。

局限：剔除不完整日期是一种稳健性口径，不是对该日期业务价值或正确性的否定。原始总体差值不应独立作为稳定模式发布。

总体读数被少量序列集中贡献

确认事实：相同采样覆盖下，Top1/Top5/Top10 序列累计读数占比分别为 19.3993% / 44.3745% / 54.8806%；共 370 条序列。

竞争解释：不同序列的负荷规模可能天然不同，不能直接认定为异常或违规。

局限：当前 TXT 无单位、用户行业和合同信息；累计读数占比不能直接转化为计费电量占比。

WITH boundaries AS (
    SELECT
        MIN(CAST(ts AS DATE)) AS first_day,
        MAX(CAST(ts AS DATE)) AS last_day
    FROM readings
),
scenarios AS (
    SELECT 'all_dates' AS scenario, FALSE AS drop_first, FALSE AS drop_last
    UNION ALL
    SELECT 'drop_first', TRUE, FALSE
    UNION ALL
    SELECT 'drop_last', FALSE, TRUE
    UNION ALL
    SELECT 'drop_both', TRUE, TRUE
),
per_series AS (
    SELECT
        x.scenario,
        r.client,
        AVG(r.value) FILTER (
            WHERE ISODOW(r.ts) BETWEEN 1 AND 5
        ) AS weekday_mean,
        AVG(r.value) FILTER (
            WHERE ISODOW(r.ts) IN (6, 7)
        ) AS weekend_mean
    FROM readings AS r
    CROSS JOIN boundaries AS b
    CROSS JOIN scenarios AS x
    WHERE (NOT x.drop_first OR CAST(r.ts AS DATE) != b.first_day)
      AND (NOT x.drop_last OR CAST(r.ts AS DATE) != b.last_day)
    GROUP BY x.scenario, r.client
)
SELECT
    scenario,
    COUNT(*) FILTER (
        WHERE weekday_mean IS NOT NULL AND weekend_mean IS NOT NULL
    ) AS comparable_series,
    COUNT(*) FILTER (WHERE weekend_mean < weekday_mean) AS weekend_lower,
    COUNT(*) FILTER (WHERE weekend_mean > weekday_mean) AS weekend_higher,
    ROUND(AVG(weekend_mean - weekday_mean), 5) AS mean_paired_delta
FROM per_series
GROUP BY scenario
ORDER BY scenario;

    SELECT
        client,
        SUM(value) AS reading_sum
    FROM readings

ranked AS (

        client,

        ROW_NUMBER() OVER (ORDER BY reading_sum DESC, client) AS rn,
        SUM(reading_sum) OVER () AS total_reading_sum

    ROUND(SUM(reading_sum) FILTER (WHERE rn <= 10)
        / NULLIF(MAX(total_reading_sum), 0) * 100, 4) AS top10_pct,
    COUNT(*) AS series_count
FROM ranked;
